2.1Model architecture: encoder and decoder stacks

How the original Transformer from Vaswani et al. (2017) is put together – component by component. Section references point to the paper.

The gist in 60 seconds

  1. No recurrence, no convolutions – only attention. So all positions are processed in parallel.
  2. An encoder turns the input sentence into one vector per token; a decoder generates the output one token at a time.
  3. Encoder layer = self-attention + feed-forward. Decoder layer = masked self-attention + encoder–decoder attention + feed-forward. Each sub-layer is wrapped in residual + LayerNorm.
  4. Both stacks have N = 6 layers; every vector has size dmodel = 512.
  5. Token embeddings + positional encodings go in at the bottom; linear + softmax produce next-token probabilities at the top.

2.1.1Core idea

Before 2017, strong sequence models were RNNs (optionally with attention, see topic 1.2) or CNNs. RNNs compute step t from step t−1, so they cannot be parallelised within a sequence, and information between distant words has to travel through many steps.

The paper proposes an architecture “based solely on attention mechanisms, dispensing with recurrence and convolutions entirely” (Abstract). Consequences:

  • Parallel computation over all positions → much faster training.
  • Any two positions are connected by a constant number of operations → long-range dependencies are easier to learn (more in 2.5).

2.1.2Encoder–decoder overview

The task in the paper is machine translation. The encoder maps the input tokens (x1,…,xn) to continuous representations z=(z1,…,zn). The decoder then produces (y1,…,ym) one symbol at a time. It is auto-regressive: every generated token is fed back in as input for the next step.

2.1.3Encoder layer

The encoder is a stack of N = 6 identical layers (Section 3.1). Each layer has two sub-layers:

  1. Multi-head self-attention – each token attends to every token of the input (details: 2.2, 2.3).
  2. Position-wise feed-forward network (2.1.5).

Each sub-layer is wrapped in a residual connection followed by layer normalisation:

output=LayerNorm(x+Sublayer(x)) Because x is added to the sub-layer output, all sub-layers and embeddings produce vectors of the same size, dmodel = 512.
Why residual + norm? The residual path lets a sub-layer learn only a change to its input and gives gradients a direct route through 6 layers. LayerNorm keeps activation scales stable. Together they make deep stacks trainable.

2.1.4Decoder layer & masking

The decoder also has N = 6 layers, but with three sub-layers, each with residual + LayerNorm:

  1. Masked multi-head self-attention over the output tokens produced so far.
  2. Encoder–decoder attention: queries come from the decoder, keys and values from the encoder output z. This is where the translation “looks at” the source sentence.
  3. Feed-forward network.

Why the mask? During training the whole target sentence is fed in at once, for speed. Without a mask, position i could simply look at token i and copy it. The mask blocks attention to later positions. Together with shifting the output embeddings right by one, the prediction for position i can only depend on positions before i – exactly the situation during generation.

2.1.5Position-wise feed-forward network

FFN(x)=max(0,xW1+b1)W2+b2 Two linear layers with a ReLU in between. 512 → 2048 → 512 dimensions (dff = 2048).

“Position-wise” means that the same network is applied to every token separately. Attention mixes information between tokens; the FFN processes each token on its own. The weights are shared across positions but differ from layer to layer.

2.1.6Embeddings, linear & softmax

Learned embeddings turn input and output tokens into vectors of size dmodel. At the top of the decoder, a linear layer projects each vector to one score (logit) per vocabulary token, and a softmax turns the scores into probabilities:

softmax(z)i=ezi∑jezj Example: z = (2, 1, 0) → (0.67, 0.24, 0.09).

Detail from Section 3.4: the two embedding layers and the pre-softmax linear layer share one weight matrix, and the embedding weights are multiplied by dmodel.

2.1.7Where positional encodings enter

Attention treats its input as an unordered set. So “dog bites man” and “man bites dog” would look identical. Therefore a positional encoding is added to the embeddings at the bottom of both stacks. The paper uses fixed sine/cosine functions of different frequencies – the formula and intuition are topic 2.4.
