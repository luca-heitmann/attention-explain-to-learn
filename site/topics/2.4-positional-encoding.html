2.4Sinusoidal positional encoding

How the Transformer learns word order without recurrence – Section 3.5 of Vaswani et al. (2017), plus Table 3 row (E) and the dropout note in Section 5.4. Where it enters the model: 2.1.7.

The gist in 60 seconds

  1. Attention by itself ignores order: shuffle the input and every token gets the same result, just shuffled.
  2. Fix: add a position vector of size dmodel to every token embedding, at the bottom of both stacks.
  3. The vector is fixed, not learned: dimension pair i is a sine/cosine of the position with its own frequency.
  4. Frequencies form a geometric series: wavelengths from 2π to 10000·2π – fast “second hands” to slow “hour hands”.
  5. Shifting by k positions = a fixed rotation of every pair → the model can easily attend by relative position.
  6. Learned position embeddings work just as well (Table 3 E); sinusoids were chosen because they might extrapolate to longer sequences.

2.4.1Why positions are needed

An RNN reads tokens one after another, so order is built in. A CNN sees local neighbourhoods. Self-attention has neither: each output is a weighted sum over all positions, and the weights depend only on the contents of query and key (see 2.2).

Consequence: if you permute the input tokens, the outputs are permuted in exactly the same way, but otherwise unchanged. “dog bites man” and “man bites dog” would produce the same set of vectors. The paper: “Since our model contains no recurrence and no convolution, in order for the model to make use of the order of the sequence, we must inject some information about the relative or absolute position of the tokens” (Section 3.5).

2.4.2How the encoding enters the model

  • The positional encoding has the same dimension dmodel = 512 as the embeddings, “so that the two can be summed”.
  • It is added, element-wise – not concatenated. The input to the first layer is xpos=Embedding(tokenpos)+PEpos.
  • This happens once, at the bottom of the encoder and of the decoder stack. Higher layers get position information only through what flows up the residual connections.
  • Dropout (Pdrop = 0.1 in the base model) is applied to this sum (Section 5.4).
Side note: the embeddings are multiplied by √dmodel before the sum (Section 3.4, see 2.1.6). The paper does not say why; a common reading is that it keeps the learned embeddings from being small next to the PE values, which lie in [−1, 1].

2.4.3The formula

PE(pos,2i)=sin(pos/100002i/dmodel)PE(pos,2i+1)=cos(pos/100002i/dmodel) pos = position in the sequence (0, 1, 2, …). Even dimensions 2i get a sine, odd dimensions 2i+1 a cosine, and both members of a pair share the same frequency ωi = 1 / 100002i/dmodel.

The paper writes “i is the dimension”. Strictly, i counts dimension pairs (0 … dmodel/2 − 1); 2i and 2i+1 are the actual dimensions.

2.4.4Frequencies and wavelengths

“Each dimension of the positional encoding corresponds to a sinusoid. The wavelengths form a geometric progression from 2π to 10000 · 2π” (Section 3.5). The wavelength of pair i is

λi=2πωi=2π·100002i/dmodel i = 0 → λ = 2π ≈ 6.3 positions. Towards the last pair, λ approaches 10000 · 2π ≈ 62 832 positions. Each step in i multiplies λ by the same factor.

Intuition: a clock with many hands. The fast hands tell neighbouring positions apart, but repeat after a few steps; the slow hands disambiguate far-apart positions. Together they give every position a distinct, bounded fingerprint – values always stay in [−1, 1], however long the sequence.

2.4.5Relative positions: a shift is a rotation

The authors chose sinusoids because they “hypothesized it would allow the model to easily learn to attend by relative positions, since for any fixed offset k, PEpos+k can be represented as a linear function of PEpos”. For one pair with frequency ω, the angle-sum identities give:

(sin(ω(pos+k))cos(ω(pos+k)))=(cos(ωk)sin(ωk)−sin(ωk)cos(ωk))(sin(ωpos)cos(ωpos)) The matrix is a rotation by the angle ωk. It depends only on the offset k, not on pos. Stacking one such 2×2 block per pair gives a single matrix Mk with PEpos+k = Mk PEpos.
Beyond the paper, but helpful: since sin·sin + cos·cos = cos(difference), the dot product PEpos·PEpos+k=∑icos(ωik) also depends only on k. The paper states only the linear-function property and calls the benefit a hypothesis.
